用你自己的模型 · 安装浏览器插件

安装「拆解 LAB · 自带模型」Chrome 插件后，上传照片时会用你在插件里配置的大模型（DeepSeek、通义千问、智谱、豆包、OpenAI、Claude 等）。API 密钥只保存在你的浏览器里，不会经过本网站。

  1. 下载插件压缩包，解压到一个固定的文件夹。
  2. 在 Chrome（或 Edge）地址栏打开 chrome://extensions，打开右上角「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择刚才解压出的文件夹。
  4. 点击浏览器工具栏里的插件图标，选择服务商、填入 API Key，点「测试连接」后保存。
  5. 回到本页刷新，上传照片时选择「我的模型」。第一次使用需在插件里允许本网站。
